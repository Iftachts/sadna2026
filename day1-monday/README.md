## מטרות למידה
בסוף היום המשתתפים:

2. **יבינו את קו המחקר הישראלי** (אליוסף ושותפים): מודעות רגשית, מנטליזציה, קונפורמיות, והכיוון של AI ככלי **הכשרה** לאנשי מקצוע.

5. **יבחינו** בין צ'טבוט, סוכן וסוכן פרואקטיבי, ויכירו את ארבעת הכלים המובילים ואת מגבלות הפרטיות שלהם בעבודה בבית הספר.
